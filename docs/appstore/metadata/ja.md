## Name
ZenHab：習慣トラッカー

## Subtitle
毎日のルーティンと目標を記録

## Promotional text

## Keywords

## Description
ZenHabは、良い習慣を身につけて続けるためのアプリです。焦らず、一日ずつ。

習慣は数秒で追加でき、曜日とリマインダーの時刻を選ぶだけ。通知やウィジェットからそのまま記録できます。連続記録、カレンダー、グラフで成長が見えます。

自分らしい習慣
• アイコン、色、説明、グループを設定
• 柔軟なスケジュール：曜日を選んで開始日と終了日を設定、無期限、または特定の1日だけ
• 約50種類の習慣テンプレート
• 記録ごとにメモを残せる

続けられるリマインダー
• 指定した時刻にお知らせし、記録するまで15分ごとに繰り返し
• 通知から「完了」「スキップ」をすぐに選べる

進捗とモチベーション
• 現在と最高の連続記録、達成率、カレンダー、グラフ、ヒートマップ
• 実績、習慣とともに育つペット、スパークで新しいペットやアバター、背景を入手
• 単語学習：14言語・各500語の頻出単語を、発音と間隔反復で
• ホーム画面とロック画面のウィジェット

プライバシー
• データはすべてiPhoneの中だけ。アカウント、広告、トラッキングなし
• バックアップの書き出しと読み込み

ZENHAB PRO
無料版では最大5つの習慣を記録できます。Proでは習慣の数が無制限になり、リマインダーの繰り返し設定、1日の目標、連続記録を失わない一時停止、限定のペット・アバター・背景、毎月100スパークのプレゼントが利用できます。

Proは月額・年額のサブスクリプション、または買い切りで利用できます。購入確定時にApple Accountに請求されます。サブスクリプションは、現在の期間が終わる24時間前までにキャンセルしない限り自動更新されます。「設定」>「Apple Account」>「サブスクリプション」で管理・キャンセルできます。
