# Скриншоты и иконка

## Что требует Apple (iPhone-only приложение)

- Нужен **один набор для iPhone 6.9"**: 1320 x 2868, 1290 x 2796 или 1260 x 2736 пикселей, вертикально, PNG или JPG без прозрачности. Меньшие экраны App Store сделает из него сам.
- От **1 до 10** скриншотов на язык. Хорошо 6-8.
- iPad не нужен: в `project.yml` стоит `TARGETED_DEVICE_FAMILY: 1` (только iPhone).
- Видео (App Preview) по желанию, до 30 секунд, можно пропустить.
- Если для языка нет своих скриншотов, App Store покажет скриншоты основного языка (en-US). Минимум: набор на английском интерфейсе и набор на русском.

С какого iPhone снимать:
- iPhone 15 Plus/Pro Max, 16 Plus/Pro Max, 17 Pro Max: скриншоты сразу нужного размера, можно грузить как есть.
- С любого другого iPhone тоже можно: `tools/appstore/make_screenshots.py` положит скриншот на фон в цветах иконки с подписью и выдаст ровно 1320 x 2868. Проще всего прислать сырые скриншоты в тред, и я соберу готовые наборы.

## План скриншотов (номер = номер в captions.tsv)

Перед съёмкой: заведи 6-8 красивых привычек с разными иконками и цветами, отметь часть за сегодня, чтобы были серии за 1-2 недели. Время в статус-баре лучше 9:41. Режим "Не беспокоить" и полный заряд, чтобы статус-бар был чистым.

| № | Экран | Что показать | Подпись (en / ru) |
|---|---|---|---|
| 01 | Сегодня | Список привычек по частям дня, часть отмечена, видна полоска недели | Your whole day at a glance / Весь день на одном экране |
| 02 | Уведомление | Развёрнутое напоминание с кнопками "Готово" и "Пропустить" (долгое нажатие на уведомление на экране блокировки) | Check off right from a notification / Отмечай прямо из уведомления |
| 03 | Статистика | Серии, график и тепловая карта или карточка привычки с календарём | Streaks, charts and calendar / Серии, графики и календарь |
| 04 | Экран Домой | Виджеты приложения рядом с иконкой ZenHab | Widgets: one tap to check off / Виджеты: отметка в одно касание |
| 05 | Питомец | Подросший питомец с фразой | A pet that grows with your habits / Питомец растёт вместе с привычками |
| 06 | Каталог | Каталог готовых привычек | 50 ready-made habits in one tap / 50 готовых привычек в одно касание |
| 07 | Слова | Карточка слова | Learn words in 14 languages / Слова на 14 языках |
| 08 | Настройки или профиль | Аватарка, достижения или экран Pro | Private by design / Только на твоём iPhone |

Порядок важен: первые 3 скриншота видны в поиске App Store без открытия страницы.

Подписи для других языков можно добавить колонкой в `captions.tsv` (код языка в заголовке).

## Сборка из сырых скриншотов

```bash
pip install pillow
python3 tools/appstore/make_screenshots.py --input raw/en --lang en-US --out appstore-shots/en-US --font /path/to/Inter-Bold.otf
python3 tools/appstore/make_screenshots.py --input raw/ru --lang ru    --out appstore-shots/ru    --font /path/to/Inter-Bold.otf
```

Файлы в `raw/<язык>/` называются `01.png`, `02.png` и так далее.

## Скриншот для ревью покупок

Отдельно нужен один скриншот экрана Pro с ценами (Настройки -> Трекер привычек Pro). Его можно сделать только в сборке из TestFlight: в SideStore-сборке цен нет. Размер любой.

## Иконка

`Habits/Resources/Assets.xcassets/AppIcon.appiconset/AppIcon.png` проверена:
- 1024 x 1024, PNG, RGB без альфа-канала: подходит для App Store;
- углы не скруглены и прозрачности нет: правильно, iOS скругляет сама;
- одна картинка для всех размеров: Xcode 26 делает остальные сам.

Отдельно загружать иконку в App Store Connect не нужно, она берётся из сборки. Тёмный и "tinted" варианты для iOS 18+/26 по желанию: без них iOS сама затемнит иконку.
