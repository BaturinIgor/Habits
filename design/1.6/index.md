# Habits (ZenHab) 1.6 — макеты новых и изменённых экранов (KAN-62)

Снято с реального приложения на интеграционной ветке `design/habits-1.6` (origin/main + ветки 1.6:
share-link, kan88-recaps, kan82-watch, kan84-analytics, kan87-pet-l10n) на iPhone 18 Pro (симулятор),
демо-данные с историей за ~2 года (итоги месяца и года выглядят как у живого пользователя).

Имена файлов в `screens/`:

- `NN-<экран>-light.png` / `-dark.png` — русский язык, светлая и тёмная тема;
- `NN-<экран>-en-light.png` / `-en-dark.png` — английский;
- `NN-<экран>-xl-light.png` (ru) и `NN-<экран>-en-xl-dark.png` (en) — крупный шрифт (Accessibility XL);
- `share-<period>-<lang>.png` — картинка, которая уходит в «Поделиться» (с QR-кодом), как её экспортирует приложение;
- `wNN-watch-<экран>-<lang>.png` — Apple Watch Series 12 (46 мм), watchOS 27.2, тёмная тема (на часах другой нет).

Номера 01–55 совпадают с каталогом 1.5 (`design/1.5`), 56+ — новые экраны.
Как переснять: `HabitsUITests/DesignCatalogUITests.swift` с `DESIGN_DIR`, `DESIGN_LANG`, `DESIGN_ONLY`
(номера через запятую), `DESIGN_SIZE` (категория шрифта); часы — `-design*` аргументы запуска `HabitsWatch` (`HabitsWatch/WatchDesign.swift`).

## Замечания по макетам

Три недочёта, найденных на первой версии макетов, исправлены в продуктовом коде (KAN-101, PR #38,
ветка `claude/habits-1.6-kan101-fixes`), и эти снимки пересняты. Старые версии лежат в `screens/before-kan101/`.

- Картинка «Поделиться» по-русски: подпись «Наведи камеру, чтобы скачать ZenHab» обрезалась до «…чтобы скачать…».
  Теперь она переносится по словам рядом с QR-кодом (`share-*-ru.png`; было: `before-kan101/share-*-ru.png`).
- Крупный шрифт, карточка итогов: слова рвались по слогам («выпол-нено», «Отме-чено», «ста-бильная»). Теперь перенос
  только между словами (`WordWrapText`), а при размерах Accessibility подпись стоит под процентом (`28/56/58/60-*xl*`).
- Крупный шрифт, «Сегодня»: карточка итогов уходила под панель вкладок. Теперь при размерах Accessibility она стоит
  сразу под неделей (`62/63-*xl*`).
- Осталось как в 1.5: при крупном шрифте числа в ленте недели и процент в кольце обрезаются «…».
- Статус-бар на часах показывает реальное время симулятора (01:00), status_bar override на watchOS не действует.

В репозитории нет самих PNG (в `docs/appstore/screenshots/` только план `README.md` и подписи `captions.tsv` для en-US и ru;
для остальных 12 языков App Store показывает en-US). Сравнение по плану из 8 скриншотов:

| № | Экран в плане | Совпадает с 1.6? |
|---|---|---|
| 01 | Сегодня | Да (карточка итогов появляется только в первые 3 дня месяца/года) |
| 02 | Уведомление | Да |
| 03 | Статистика | **Обновить**, если снята верхняя часть экрана статистики: вместо одного входа «Итоги недели» теперь три (неделя, месяц, год). Если снят календарь привычки — не нужно |
| 04 | Виджеты | Да |
| 05 | Питомец | **Обновить ru** (и de/zh-Hans/ko, если для них есть свои наборы): «150 XP» → «150 опыта». en-US без изменений |
| 06 | Каталог | Да |
| 07 | Слова | Да |
| 08 | Настройки / профиль | Если снят низ настроек — там теперь выключатель статистики (только в сборке App Store). Подпись «Только на твоём iPhone / без аккаунта» остаётся верной, но рядом с выключателем «Отправлять анонимную статистику» её стоит перепроверить (обещание «Private by design» в тексте не нарушено: отправляются только экраны и кнопки) |

Чего нет в наборе и что стоит добавить в 1.6: Apple Watch (отдельный набор скриншотов для часов в App Store Connect,
без него страница не покажет приложение для часов) и карточка «Итоги месяца/года» с QR — сильный кадр для подписи вроде
«Итоги месяца, которыми хочется поделиться».
