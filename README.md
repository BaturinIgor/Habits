# Привычки

Трекер привычек для iPhone. Все данные хранятся только на устройстве.

## Возможности

- Привычки с иконкой, цветом, описанием и группой
- Расписание: регулярно по дням недели (с датой начала и окончания или бессрочно) либо один раз в выбранный день
- Напоминание в выбранное время. Если привычку не отметить, напоминание повторяется каждые 15 минут (количество повторов настраивается). Кнопки "Готово" и "Пропустить" прямо в уведомлении останавливают повторы
- Заметки к отметкам
- Статистика: серии, процент выполнения, календарь, графики, тепловая карта
- Виджеты для экрана Домой (с отметкой прямо из виджета) и экрана блокировки

## Сборка

Каждый push в `main` запускает GitHub Actions: проект генерируется через XcodeGen, собирается на macOS и публикуется в Releases как `Habits.ipa`.

Последняя сборка: https://github.com/BaturinIgor/Habits/releases/latest

## Установка через SideStore

1. Установи SideStore на iPhone по официальной инструкции: https://docs.sidestore.io (понадобится компьютер один раз).
2. Открой ссылку на последнюю сборку в Safari на iPhone и скачай `Habits.ipa` в Файлы.
3. В SideStore открой вкладку "My Apps", нажми "+" и выбери `Habits.ipa`.
4. SideStore сам продлевает подпись каждые 7 дней в фоне, если телефон хотя бы иногда подключается к Wi-Fi.

## Обновление

Скачай новый `Habits.ipa` из Releases и установи его поверх через SideStore. Данные сохранятся.

## Android

Исходники в папке `android/` (Kotlin, Jetpack Compose, Glance для виджета). Каждый push в `android/**` собирает подписанный `Habits.apk` и публикует его в Releases с тегом `android-N`.

Установка: скачай `Habits.apk` на телефон, открой его и разреши установку из этого источника. Новые сборки ставятся поверх, данные сохраняются.
